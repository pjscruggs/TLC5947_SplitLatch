# Contributor Code of Conduct

This project expects respectful, constructive participation in issues, pull
requests, and other project spaces.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, publishing private information without permission, or sustained
disruption of project discussion.

Maintainers may edit, hide, or remove comments and may restrict participation
when needed to keep the project usable for contributors.

This is an unofficial fork of Adafruit_TLC5947. Conduct reports and project
maintenance questions for this fork should be handled in this fork's GitHub
repository, not through Adafruit support channels.
